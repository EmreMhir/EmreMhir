## Project spotlight: PartSense

PartSense brings together a computer vision model, an edge device, an API and a mobile application for screw and nut analysis.

- **Data:** image collection and Roboflow annotation, followed by synthetic data augmentation.
- **Model:** YOLOv8 instance segmentation with model comparison and evaluation.
- **Application:** NVIDIA Jetson deployment, a FastAPI backend and a Flutter client.
- **Reported experiment:** a hybrid training set of **1,680 images**, including **1,303 real images**, achieved **55.7% overall mask mAP50–95** on the project's real-image test set.

See the [project documentation](https://github.com/EmreMhir/PartSense#readme) for experimental context, per-class results and limitations. The underlying Roboflow dataset is not distributed in the public repository.
